🍼 TwinFeed

Helm Repository

Official Helm charts for TwinFeed - A mobile-friendly breastfeeding tracker for twins

📦 Quick Start

# Add the repository
helm repo add twinfeed https://mrowling.github.io/twinfeed
helm repo update

# Install TwinFeed
helm install twinfeed twinfeed/twinfeed

🛠️ Configuration Examples

Development Deployment

helm install twinfeed twinfeed/twinfeed \
--set image.backend.tag=latest \
--set image.frontend.tag=latest \
--set backend.service.type=NodePort

Production with Ingress

helm install twinfeed twinfeed/twinfeed \
--set global.imageTag=v1.0.0 \
--set ingress.enabled=true \
--set ingress.hosts[0].host=twinfeed.example.com \
--set autoscaling.enabled=true

High Availability

helm install twinfeed twinfeed/twinfeed \
--set replicaCount=3 \
--set autoscaling.enabled=true \
--set autoscaling.minReplicas=2 \
--set autoscaling.maxReplicas=10 \
--set backend.persistence.size=10Gi
